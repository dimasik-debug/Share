📚 LitRes Downloader

Скачивание книг и аудиокниг с LitRes.ru + Suno музыки

🎯 Что это

Набор букмарклетов (закладок-скриптов) для скачивания контента:

  • 📚 Книга v31 — PDF, FB2, EPUB → ZIP (или HTML через JSON fallback)
  • 🎧 Аудио v1.1 — MP3 по главам, готовый ZIP или M4B
  • 📖 Reader JSON — если ZIP 404, качает главы и собирает HTML
  • 🎵 Suno — скачивание треков с suno.com
  • 🎛️ Выбор — сам определяет что на странице (книга или аудио)

🎬 Как использовать


        
📚 Для книг

        
    
            
  1. Открой нужную книгу на litres.ru
    2. 
            
  2. Кликни закладку 📚 LitRes Книга v31
    3. 
            
  3. Внизу справа появится панель управления
    4. 
            
  4. Жми ▶▶ Старт — скрипт сам найдёт ZIP или уйдёт в JSON fallback
    5. 
        


        
🎧 Для аудиокниг

        
    
            
  1. Открой аудиокнигу (URL содержит /audiobook/)
    2. 
            
  2. Кликни закладку 🎧 LitRes Аудио
    3. 
            
  3. Выбери: 📦 ZIP (один файл), 🎵 M4B (audiobook) или 🎧 Главы (диапазон)
    4. 
        


        
📖 Если ZIP не работает

        
    
            
  1. В v31: включён 📖 JSON чекбокс → автоматом уйдёт в JSON fallback
    2. 
            
  2. Или жми фиолетовую кнопку 📖 Reader (JSON) в панели
    3. 
            
  3. Результат: красивый HTML-файл (открой в браузере, Ctrl+P → Save as PDF)
    4. 
        


        
🎵 Для Suno

        
    
            
  1. Открой suno.com → войди → открой нужный трек/плейлист
    2. 
            
  2. Кликни закладку 🎵 Suno Downloader
    3. 
            
  3. Скрипт покажет панель со списком треков — качай всё или по одному
    4. 
        


        

            ⚠️ Важно: нужна активная подписка LitRes (для книг/аудио) или аккаунт Suno. Скрипт использует твою сессию браузера — токены не передаются третьим лицам.
        

    


    
    
    
    

        
❓ FAQ


        
🔒 Это безопасно?

        
Да. Скрипты загружаются с твоего же репозитория на GitHub. Все запросы идут на api.litres.ru, www.litres.ru и suno.com с твоими куки. Никакие данные не отправляются наружу.


        
📥 Куда качается?

        
В папку загрузок браузера. По умолчанию это Загрузки или Downloads.


        
🎧 В каком формате аудио?

        
    
            
  • 📦 ZIP — готовый архив со всеми MP3-главами (от LitRes)
    • 
            
  • 🎵 M4B — audiobook одним файлом с обложкой (для iPhone, VLC)
    • 
            
  • 🎧 Главы — свой ZIP, можно выбрать диапазон
    • 
        


        
📚 Что в ZIP книги?

        
PDF-страницы (JPG/PNG) + инструменты конвертации x64.rar + README с инструкцией по сборке в PDF.


        
📖 Что в JSON fallback?

        
Один HTML-файл с текстом всей книги. Открой в браузере, потом Ctrl+P → Save as PDF. Если включён 📦 Tools — соберётся ZIP с HTML + x64.rar.


        
🎵 Что качает Suno?

        
MP3-файлы треков с обложками, метаданными (название, автор, длительность). Работает как для отдельных треков, так и для плейлистов.


        
🐛 Не работает?

        
    
            
  • Обнови страницу (F5) и кликни закладку снова
    • 
            
  • Проверь что залогинен в LitRes / Suno
    • 
            
  • Открой F12 → Console и посмотри ошибки
    • 
            
  • Попробуй другую закладку (Книга / Аудио / Reader)
    •
